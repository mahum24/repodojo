Google now pilots code-comprehension interviews with an AI assistant

Read any codebase. Find the bug. Prove you didn't just trust the AI.

RepoDojo turns a real GitHub repo into a guided tour, then plants a real bug, verified by the repo's own tests, and puts you in a 3-panel interview with an AI assistant that is sometimes wrong. Your fix is checked by the test suite, by hidden edge-case tests and by a blast-radius analysis, then scored the way interviewers now score AI fluency.

Choose a repo

The online demo runs the curated repos above, because a repo's tests are real code. Run RepoDojo yourself to use any small Python repo (see README).
